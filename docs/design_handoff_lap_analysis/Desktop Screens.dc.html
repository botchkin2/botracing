Desktop screens · v1 · 1440 × 900

Session · Compare · Corner, on desktop

These use the same data, tokens and rules as the phone screens, but the layouts are built for a big screen. The phone shows one question per view with drill-down; desktop puts related views side by side. Sessions become a rail beside the open session. Compare shows the whole-lap overview and the detail window together, with the map, the exact values under the pointer and the corner grid all visible. Corner shows the distribution, a zoomed track map with every lap's brake point, the full lap table and the traces at the same time.
