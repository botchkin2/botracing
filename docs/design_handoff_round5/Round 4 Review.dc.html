Decisions
  • 10-second read: laps, stops and stop laps sit in the one raised card, in 28 pt mono. Race and Per tank both land above the fold.
  • Card order follows the arithmetic: Race → Per tank → Stops → To drop a stop → Per green lap. The source data goes last because it is the evidence, not the answer.
  • Rules collapse to a 3 × 2 grid once set; the named rule set is a chip, like track and car. Edit opens a sheet.
  • Which meter limits: both meters are drawn as laps-per-tank bars on one scale. The shorter one is full-ink and boxed “RUNS OUT FIRST”; the other is faint. No colour carries it: amber is UI-only and red means slower.
  • Median and p90 share one bar (bar = median, notch = p90), and each bar prints its division once.
  • To drop a stop gives the use needed and a count of his laps at or under it, always with a denominator, and never says whether it is achievable.

Decisions
  • Pit note row: fixed 24 pt, one line, no checkbox, on --surface so it never reads as a lap. The amber PIT box replaces the “Pit:” prefix; the string is 290 pt at 10.5 pt mono and fits 358. If a value grows, drop “(0.7 laps)” before wrapping.

Decisions
  • Desktop is a single column: map at full width (470 pt), lanes, then the transport pinned to the bottom. Nothing sits beside the map.
  • Your car is the amber marker because it is the playback position; other cars are --text-muted. The radar uses the same two inks.
  • Zoom (100 / 200 / 400 m) appears only in Follow. Track is always the whole circuit.
  • Radar inset: bottom-right, the only floating element on the map, with a caption for range and orientation.
  • Lanes share one x-axis and one amber cursor. PIT is amber because pit markers are amber everywhere; the other lanes are neutral fills; PASS is a tick. The lane key states each threshold; replace these with your actual rules.
  • Race / 10 laps / 3 laps windows centre on the cursor.
  • Rates: desktop shows all seven (0.25× to 16×). At 375, the Transport keeps four (0.25×, 1×, 4×, 16×) so every segment stays 44 pt wide; put the full list in a ▾ picker if all seven are needed.

Decisions
  • Column order: Delta, Speed, Brake, Throttle, Steering, Racing line. Delta is 90 pt; Brake and Throttle 64; Steering 40.
  • One cursor fraction drives every chart and every header value. The metre axis prints once, under the last chart.
  • Dim laps use --lap-muted (1 pt, 45 %) at any count, so tints stay reserved for chips. This is a change to the 7–19 tint rule for context laps only.
  • Racing line: 0 = the game’s centre path (zero line); the grey line is the edge on the car’s side, and it switches side with the car.
  • Strips: a count always has a denominator (“12 of 38 laps”), and the threshold goes in the sentence. The row keeps the DotStrip height so the column never jumps.
  • The cell row shows which laps, in the same order as the lap table. Omit it on “No brake”, where it would be empty.

Per-chart “?”

Closed and open · tap “?” to toggle
?
WhatCar speed along the corner, one line per lap. MeasuredFrom game telemetry, sampled every metre from the turn’s entry. DirectionHigher = faster. The lowest point of each line is its minimum speed. LinesWhite = L16, the reference. Tap a value above to hide that lap.
Spec, for reuse
  • Affordance: a 20 pt boxed “?” in mono, --control-border, at the right end of the ChartHeader’s first line. Hit area 44 × 44.
  • Open: the box inverts (--text on --bg), the same treatment as a selected segment. The panel opens inline under the header and pushes the chart down. It never overlays data.
  • Panel: --surface-raised, 6 pt radius, and 2–4 rows with fixed keys: WHAT, MEASURED, DIRECTION, plus optionally LINES. Explainer type at full ink.
  • Close: tap “?” again. Opening one closes any other. It is closed again on the next visit; nothing is remembered.
  • Component change: add help (rows) and helpOpen / onHelp to ChartHeader rather than wrapping it.

Decisions
  • Six equal items is too many for a 375 bar, and four of them need an open session. The phone bar keeps three destinations that work without one: Sessions, Plan, Settings.
  • Session, Compare, Corner and Race become a segmented row under the session title (Laps / Compare / Corner / Race). Race appears for race sessions only.
  • Desktop top bar (see item 4): Sessions | Session · Compare · Corner · Race | Plan, with Settings on the right. The dividers separate “this session” from pre-race.
  • Mark: a half-gauge, drawn in 1.5 pt outline to the Lucide grid. No letter, because P already means Practice. Treat it as an addition to a text-first system, and only use it if an icon row ships; otherwise the label “Plan” is the mark.
