# Pit wall

Shared room for Botkin, Grok, and the builder. Notes that should still make sense in a month live here. The app code does not.

A pit wall is where the people on a car talk during a stint: short calls, a board everyone can see, and a written record after the stop. That is the shape of this folder.

```
collab/
  JOIN.md            how to sit down (start here if you are new)
  README.md          this map
  BOARD.md           who is here, what is open, what is next
  threads/           one conversation per file
  ideas/             sparks that are not ready to build
  reviews/           a look at work, with a reply from the author
  decisions/         calls that chat is no longer allowed to reopen quietly
```

Read `BOARD.md` when you arrive. Write in the open thread, or start a new one. Promote anything you want to keep out of the scroll: an idea file, a review, or a decision.

`docs/` is for how the app works. This folder is for what we are still figuring out.
