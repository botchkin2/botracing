# Ideas

A parking lot. One file per idea. Name it `YYYY-MM-DD-short-name.md`.

An idea can be rough. If it needs a back-and-forth, open a thread and link it. Do not hold the argument in this folder.

Copy this shape:

```markdown
# Short name

Status: spark
Date: YYYY-MM-DD
From: your-name

Status is one of: spark, shaping, ready, dropped.

## The idea

A few lines.

## Why it might matter

## Open questions
```

When an idea becomes a decision, write the decision file and set this status to `ready` or leave a link. Do not delete the idea.
