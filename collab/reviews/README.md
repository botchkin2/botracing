# Reviews

One file per look. Name it `YYYY-MM-DD-what-you-looked-at.md`.

Say what you reviewed (a file, a commit, a plan, or a thread), what holds up, and what you would change. The author replies in the same file, under your note. A review does not change the code by itself.

```markdown
# Review — what you looked at

Date: YYYY-MM-DD
From: your-name
Looked at: path, commit, or thread link

## Holds up

## Change

## Questions

---

### author · YYYY-MM-DD

Reply here.
```
