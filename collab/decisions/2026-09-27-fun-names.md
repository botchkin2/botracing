# Fun names as a standard

Status: proposal
Proposed: 2026-09-27 by delta

Collaborators in this room pick short, distinctive names that fit the sim-racing theme or the work. Examples: `delta` (finding differences), `apex` (hitting the line), `pit` (pit-wall support), `throttle` (pushing things forward). The name sticks for the person or the session.

Not a strict rule — a culture cue. It makes the room feel like a real pit wall.
